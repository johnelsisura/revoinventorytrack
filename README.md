## ✨ Features

- 🔐 **Auth** — Username + PIN login (no email needed)
- 📊 **Dashboard** — Summary cards, sponsor progress bars, recent transactions
- 🤝 **Sponsors** — Add, edit, delete sponsors with tier badges (Gold / Silver / Bronze / In-Kind)
- 📦 **Items** — Grouped by category, auto-computed stock status
- 📜 **Transactions** — Full IN/OUT movement log with distribution type tracking
- 👥 **Team** — View all members, edit your own profile and position
- 🔍 **Global Search** — Search across sponsors, items, and transactions
- 🔄 **Auto-refresh** — Syncs data every 30 seconds across all devices
- 📤 **Export CSV** — Download transactions as CSV
- 🖨️ **Print View** — Clean print layout for items inventory

## ⚙️ Setup Instructions

### 1. Set up Supabase

- Go to your [Supabase project](https://supabase.com)
- Open the **SQL Editor**
- Copy and run all the SQL from [`SETUP.md`](./SETUP.md)

### 2. Deploy to GitHub Pages

```bash
# Clone the repo
git clone https://github.com/your-username/pup-revo-2026.git
cd pup-revo-2026

# Add your index.html (generated by Claude AI)
# Then push to GitHub
git add .
git commit -m "Initial commit"
git push origin main
```

- Go to your repo → **Settings** → **Pages**
- Source: `main` branch → `/ (root)`
- Click **Save**
- Wait ~1 minute → your app is live! 🎉

### 3. First-time Use

1. Open the app URL
2. Click **Sign Up**
3. Enter your username, PIN, and position
4. Start adding sponsors and items!
